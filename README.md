<h1><span class="selected">Responsive Sign-Up Form 📝</span></h1><p><span class="selected">A modern, single-page registration form designed with a focus on clean aesthetics, responsiveness, and user experience, built using standard web technologies.</span></p><p><span class="selected">This project demonstrates strong front-end styling techniques using purely </span><strong><span class="selected">Custom CSS</span></strong><span class="selected"> to achieve a modern card layout, shadow effects, and seamless transitions, mimicking the quality of utility-first frameworks.</span></p><h2><span class="selected">✨ Features</span></h2><ul><li><p><strong><span class="selected">Responsive Grid:</span></strong><span class="selected"> Utilizes CSS Grid to organize Aesthetics:</span></strong><span class="selected"> Features smooth focus transitions, rounded corners, and a raised "card" container with a clean shadow effect.</span></p></li><li><p><strong><span class="selected">Input Feedback:</span></strong><span class="selected"> Leverages CSS pseudo-classes (</span><code><span class="selected">:required:valid</span></code><span class="selected">) to and CSS ensure placeholder text for the Date of Birth and Gender selection fields is managed correctly before user input.</span></p></li><li><p><strong><span class="selected">Accessibility:</span></strong><span class="selected"> Uses </span><code><span class="selected">rem</span></code><span class="selected"> and </span><code><span class="selected">px</span></code><span class="selected"> units for appropriate sizing and spacing.</span></p></li></ul><h2><span class="selected">💻 Technologies Used</span></h2>
Technology | Purpose
-- | --
HTML5 | Defines the form structure and input elements.
